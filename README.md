# Sliide Peek

Sliide Peek is a Kotlin Multiplatform Compose foundation for a small User Activity Manager app. The app will eventually browse GoREST users, posts, comments, and todos with loading/error states, dark mode, shimmer, and adaptive phone/tablet layouts.

## Current status

Roadmap item 12.1, project foundation, is in progress/completed:

- Android and iOS KMP project generated from the Android Studio template.
- Shared Compose UI entry point is present in `SliidePeek/shared`.
- Android app module is present in `SliidePeek/androidApp`.
- iOS app/project is present in `SliidePeek/iosApp`.
- Basic app shell displays “Sliide Peek” and “Project foundation ready”.

Networking, navigation, feature screens, GoREST integration, shimmer loading, and adaptive tablet layouts are planned in later roadmap items.

## Project layout

```text
SliidePeek/
  androidApp/   Android application entry point
  iosApp/       iOS application entry point
  shared/       Shared Kotlin/Compose code
```

Important shared files:

- `SliidePeek/shared/src/commonMain/kotlin/com/sliide/useractivity/App.kt`
- `SliidePeek/shared/src/commonMain/kotlin/com/sliide/useractivity/ui/theme/AppTheme.kt`

## Build and run

From the generated KMP project directory:

```bash
cd SliidePeek
./gradlew projects
./gradlew :shared:compileKotlinMetadata
./gradlew :androidApp:assembleDebug
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64
```

Run Android from Android Studio using the generated Android run configuration. Run iOS by opening `SliidePeek/iosApp` in Xcode or using the generated Android Studio/Xcode integration if available.
