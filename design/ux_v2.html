User Management System — UX Wireframes

Re-aligned to the official challenge: a focused, high-polish user-management app. Four flows carry the experience — a Smart User Feed, Add User, Delete with Undo, and graceful Offline handling. Phone uses a modal sheet for add and long-press for delete; iPad uses a Feed | Action-Panel master–detail. Grayscale blocks with real labels; amber marks selection & active only; clay-red marks destructive. Hi-fi (Signal, light + dark) comes after this structure is agreed.

01

Phone · Smart User Feed — all states

The home of the app. Each row carries name, email, a relative “last active” timestamp and a status chip. A FAB adds a user. Shimmer placeholders mirror the row layout so the jump to content doesn’t shift anything. Empty, error, offline and refreshing states all share one stable shell.

Delete & undo logic
  • Long-press is the trigger (per brief) — see motion note on discoverability.
  • Confirmation guards an irreversible-feeling action; Cancel left, Delete right.
  • Removal is optimistic: row leaves immediately, kept in memory until the window closes.
  • Undo restores to the exact original index, not the top.
  • If the snackbar times out, the delete is committed to the API.
  • Delete failure (after commit) re-inserts the row + shows an error snackbar — see components.

06

Motion notes

Written guidance for the four moments that carry the “expensive but simple” feel. Easing & durations target Material 3 standard motion; the hi-fi prototype will reference these.

▤Shimmer → content
Skeleton sweep runs left→right on a 1.4s loop. When data lands, skeletons cross-fade into real rows (no slide) so nothing jumps — skeleton geometry already matches the row.
fade 200ms · ease-out · stagger 30ms/row
▦Add form entry
Sheet slides up from the bottom edge while the scrim fades in. On success the sheet slides down; the new row expands in height + fades at the top of the feed, then a brief amber highlight decays.
sheet 280ms · emphasized-decelerate · highlight 1.2s decay
✕Delete removal
On confirm the row collapses its height to 0 while fading + sliding slightly left; rows below slide up to close the gap. Snackbar rises from the bottom as the row leaves.
collapse 240ms · emphasized-accelerate · reflow 200ms
↺Undo restore
Tapping Undo reverses the collapse at the row’s original index — height expands back, fades in, brief amber highlight confirms it’s back. Snackbar dismisses immediately.
expand 240ms · emphasized-decelerate · highlight 1s
⌖Long-press affordance
Press & hold ~450ms: row scales to 0.98 with a radial ripple + a single haptic tick at threshold, then the confirm dialog springs in. First-run shows a one-time hint (“Hold a user to manage”).
hold 450ms · ripple 300ms · dialog spring 260ms
⟳Refresh
Pull-to-refresh spins the app-bar icon; existing rows stay in place (no skeleton wipe). New/updated rows fade their timestamp to “just now”. Offline attempt bounces back to the cached banner.
spin 900ms/turn · timestamp fade 200ms
Once structure lands → Signal hi-fi (light + dark) with real elevation, M3 FAB/snackbar mechanics & these motion specs applied. ✎
