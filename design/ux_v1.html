User Activity Manager — UX Wireframes

A flow-map of the core experience: browse users → open a profile → read posts & comments, scan todos. Phone uses simple push/stack navigation; iPad uses an adaptive 2-pane master–detail. Grayscale blocks with real labels — amber marks selection & active states only. Hi-fi light/dark comes after this structure is agreed.

Why these choices
  • Skeleton rows match the real row geometry → no layout jump on load.
  • Status as a chip, not colour-only — readable for everyone, both themes.
  • Empty vs error are distinct: empty offers a way out, error offers retry.
  • Filter is a 3-way segmented control, not a hidden menu.
02

Phone · Drill-down flow (push / stack)

Back button drills up one level each time. User Detail is a single scroll: profile header, then stacked Posts and Todos sections with headers. A post pushes Post Detail, which carries the full body and a comments list.

Flow notes
  • One scroll for the profile — no tabs to lose state between.
  • Section headers (Posts · 8 / Todos · 5) double as “see all” affordances via the › chevron.
  • Comments shimmer independently — the post body shows instantly while comments fetch.
  • “No comments yet” + comment error reuse the same centred state block from §01.
03

iPad / Tablet · 2-pane master–detail

Not a stretched phone. The list stays persistent on the left; selecting a user updates the right detail pane in place (selected row highlighted) rather than pushing a full-screen page. Portrait keeps the same model with a narrower list.
