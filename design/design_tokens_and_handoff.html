Handoff sheet

Every value behind the User Management System "Signal" screens, consolidated for implementation. Colors are theme-paired (light / dark); type, spacing, radii and status semantics are named so they map cleanly onto a Compose ColorScheme / Typography / Shapes. v2 adds the re-scoped components (FAB, snackbar, text fields, segmented control, dialog, bottom sheet, offline banner) each mapped to its Material 3 composable, plus a motion table. Pair this with the Engineering Spec sheet for logic, API contract & copy.

Radii & borders

squared, technical

05

Status & semantics

accessible in both themes
Active Inactive Error
Always pair colour with a label or icon — never colour alone. Mapping:
· User status → green Active / ink-3 Inactive
· Validation success → green (field valid tick)
· Errors, destructive (delete), failed submit → danger
· Selection, links, primary action, FAB, valid-focus, snackbar action → accent
· Offline / cached banner → neutral line-2 fill, ink-2 text (informational, not alarming)
